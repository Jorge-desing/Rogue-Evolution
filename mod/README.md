# Plantilla del mod

`manifest.json` es un punto de partida para el formato integrado de Rogue Command que está confirmado por los archivos de ayuda instalados. La lista está vacía, así que todavía no aplica cambios.

El formato de balance documentado solo sobrescribe entidades existentes. Esta plantilla no agrega unidades, niveles, mundos ni prefabs. Para ese contenido existe el cargador externo descrito en el [README del repositorio](../README.md); ambos mecanismos son independientes. No copies esta plantilla a la instalación del juego como si implementara por sí sola esa ampliación.
