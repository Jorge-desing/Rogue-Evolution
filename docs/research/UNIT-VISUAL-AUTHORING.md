## ImageGen card sprites

The prompt records below document an earlier card-art pass, not the current model art direction. Use the current 3D authoring skill for future model work; card PNGs were not regenerated in this realism pilot.

The Unity authoring project contains nine tracked card PNGs: seven ImageGen-authored PNGs plus Blender-rendered ArachnidHexapodCard.png and OverlordCommandHQCard.png (1254 × 1254, dark navy background, isometric camera) rendered from their source blends so each card matches its model. Each unit's Blender preview was used to preserve its silhouette; the new Ironclad Walker and Surge Arc Tank images also used the Colossus Siege card for lighting and background style. Their source PNGs are 1254 × 1254: `IroncladWalkerCard.png` SHA-256 `68877148ce681f92a810398d492c456bcb97ef411b35f8d6871e2d1a02a4784a`, and `SurgeArcTankCard.png` SHA-256 `db7283d8c2542a8ec6f0074cdf5e4c41500df2769ec4b1b3fe9677e45455b003`. Unity imports each PNG as a single Sprite with Point filtering, no mipmaps, Clamp wrap mode, Uncompressed texture data, and a 128 × 128 maximum size. The scaffolder contains no procedural card drawing code and fails if a source PNG is missing or does not import as a 128 × 128 Sprite.
