# Plan: v1.4.0 — Active Skills & Combat Modifiers

## Goal
Extend the ability system to support active skills with targeting and combat modifiers, leveraging the `ActiveSkill` and `CombatBoost` classes identified via REA.

## Current Context / Assumptions
- **Project Root:** `C:\Users\Alex\Documents\Mod Rogue Command`
- **Active Branch:** `codex/rogue-unit-balance-20261018`
- **Existing:** `abilities` field supports `id` + `value` (passive stat modifiers). `RuntimeMutationManager` applies these via reflection.
- **REA Findings:** `ActiveSkillAtPosition`, `ActiveSkillOnTarget`, `ActiveSkillWithoutTarget` classes exist. `SkillHelper` provides targeting. `CombatBoost` provides temporary combat enhancers. `EntityValueModifier.Modify()` is the buff hook.
- **Gap:** No support for active skills (click-to-cast abilities) or temporary combat boosts. Only passive stat overrides exist.

## Architecture / Proposed Approach
1. **Schema Extension:** Add `activeSkills` array to unit definition with `skillType` (Position/Target/Self), `cooldown`, `manaCost`, and `effectValue`.
2. **Combat Boosts:** Add `combatBoosts` array for temporary stat enhancers with `duration` and `multiplier`.
3. **Runtime Registration:** Wire active skills into the unit's skill list during entity registration.
4. **Targeting Bridge:** Use `SkillHelper` methods for custom targeting validation.
