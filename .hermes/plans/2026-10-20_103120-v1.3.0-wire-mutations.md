# Plan: v1.3.0 — Wire Runtime Mutations & Apply Abilities/AI Overrides

## Goal
Wire the existing `RuntimeMutationManager` into the loader pipeline so that `abilities` and `aiOverrides` defined in content packs are actually applied to game entities at runtime, completing the v1.2.0 feature set.

## Current Context / Assumptions
- **Project Root:** `C:\Users\Alex\Documents\Mod Rogue Command`
- **Active Branch:** `codex/rogue-unit-balance-20261018`
- **v1.2.0 Status:** Schema, DTOs, validation, and `RuntimeMutationManager` class all exist, but the manager is never instantiated or called. `abilities` and `aiOverrides` are validated but never applied.
- **Gap:** The `RuntimeMutationManager` is a standalone utility with no integration point in `ContentPackRuntimeLoader`.

## Architecture / Proposed Approach
1. **Instantiate Manager:** Add a `RuntimeMutationManager` field to `ContentPackRuntimeLoader`, initialized with the existing `Log` delegate.
2. **Apply During Registration:** In `OnEntityRowsRegistered()`, after entity rows are appended, iterate over loaded units and apply their `abilities` (as buff mutations) and `aiOverrides` (as AI behaviour mutations) using the manager.
3. **Apply During AI Init:** In `OnAiBehaviourInitialized()`, apply `aiOverrides` from the unit definition to the freshly created AI behaviour.
4. **Diagnostics:** Track mutation success/failure counts in the loader diagnostics snapshot.
